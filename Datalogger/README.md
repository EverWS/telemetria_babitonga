# Datalogger Rev B

Firmware Rev B do RP2040. Este diretório não mantém mais o caminho legado.

O firmware coleta ADS1115/ACS758, INA226 low-side, fluxo, DS18B20 e GPS NEO-6M,
grava o CSV Rev B no microSD e envia frames UART com CRC para a Heltec.

## Build

```text
make compile
make upload PORT=COMx
make monitor PORT=COMx
```

As pinagens ativas estão centralizadas em `config/pins_rev_b.h` e as calibrações
em `config/rev_b_config.h`.

## Temperature sensor addresses
The temperature sensors have a part of their address physically written to them for quick identification.
Here are the full addresses:
```
0x28, 0xE6, 0xDD, 0x43, 0xD4, 0xE1, 0x3C, 0x74
0x28, 0x57, 0x6C, 0x57, 0x04, 0xE1, 0x3C, 0xE9
0x28, 0x77, 0x00, 0x43, 0xD4, 0xE1, 0x3C, 0x90
0x28, 0x1D, 0x5E, 0x43, 0xD4, 0xE1, 0x3C, 0x7B
0x28, 0xB8, 0x88, 0x43, 0xD4, 0xE1, 0x3C, 0x0E
0x28, 0x5F, 0x85, 0x43, 0xD4, 0xE1, 0x3C, 0x4E
```
